# Streamlit UI 설계

## 1. 목표

사용자가 BOM 관련 질문을 자연어로 입력하고, 답변과 구조화된 데이터를 이해하기 쉽게 확인할 수 있는 화면을 제공한다.

## 2. 초기 화면 구성

- 프로젝트 제목과 설명
- 채팅 입력창
- 대화 이력
- 답변 메시지
- 조회 결과 DataFrame
- 오류 및 안내 메시지

## 3. 향후 화면 구성

- 제품 선택 및 검색
- BOM Tree
- Validation 결과 요약
- 변경 영향 분석
- Tool 실행 상세 정보
- CSV 다운로드

## 4. Session State

관리 후보:

- 대화 이력
- 마지막 Tool 결과
- 선택된 제품
- Agent 인스턴스
- 데이터 로딩 상태

## 5. UI 원칙

- 사용자가 ID 형식을 몰라도 예시를 제공한다.
- 오류를 Python Traceback 그대로 노출하지 않는다.
- 표와 자연어 설명을 함께 제공한다.
- 데이터가 많을 때 필터와 다운로드를 제공한다.
- Agent의 불확실성과 데이터 부재를 명확히 표시한다.
