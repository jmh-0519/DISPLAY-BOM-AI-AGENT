## TS-001: CSV 파일을 찾을 수 없음

### 증상

`FileNotFoundError`가 발생한다.

### 원인 후보

- 실행 위치가 프로젝트 루트가 아님
- `data` 폴더 또는 파일명 불일치
- 파일 확장자 숨김으로 `.csv.csv`가 됨

### 해결

- 프로젝트 루트에서 실행한다.
- `Path.resolve()`로 실제 탐색 경로를 확인한다.
- 파일명과 폴더 구조를 확인한다.

### 예방

- 오류 메시지에 절대 경로를 포함한다.
- 실행 시작 시 필수 데이터 파일 검증을 추가한다.

## TS-002: CSV 한글 또는 BOM 인코딩 문제

### 증상

한글이 깨지거나 첫 번째 컬럼명 앞에 특수 문자가 보인다.

### 해결

```python
pd.read_csv(file_path, encoding="utf-8-sig")
```

### 참고

여기서 BOM은 Bill of Materials가 아니라 UTF-8 Byte Order Mark를 의미한다.
