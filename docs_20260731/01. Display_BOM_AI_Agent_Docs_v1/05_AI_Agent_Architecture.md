# AI Agent 아키텍처

## 1. Agent의 역할

BOM AI Agent는 사용자의 자연어 질문을 이해하고 적절한 Tool을 선택하며, Tool 결과를 근거 기반의 자연어 답변으로 변환한다.

## 2. Agent가 담당하는 것

- 질문 의도 파악
- Tool 선택
- Tool 인자 생성
- 여러 단계 실행이 필요한지 판단
- 결과 요약 및 설명
- 데이터가 없거나 불확실할 때 명시

## 3. Agent가 담당하지 않는 것

- BOM 수량 계산의 최종 로직
- 승인 및 호환성 규칙 판정
- 임의 SQL 실행
- 데이터 조작 및 자동 승인
- 존재하지 않는 데이터 추측

## 4. 기본 처리 흐름

```text
사용자 질문
  ↓
의도 및 필요한 정보 분석
  ↓
Tool 선택 또는 일반 응답
  ↓
입력 스키마 구성
  ↓
Tool 실행
  ↓
결과 검증
  ↓
근거 기반 답변 생성
```

## 5. 초기 Intent 예시

- 인사 및 사용법 질문
- 제품 조회
- 자재 검색
- BOM 조회
- 지원하지 않는 요청

## 6. 응답 원칙

- 조회 기준 ID와 결과 건수를 표시한다.
- 테이블에 적합한 결과는 구조화해 UI에 전달한다.
- 결과가 없으면 없다고 답한다.
- 오류 원인과 사용자가 수정할 입력을 안내한다.
- Tool 결과에 없는 사실을 추가하지 않는다.

## 7. 향후 고려사항

- 대화 메모리 범위
- 다중 Tool 호출
- Agent Loop 최대 횟수
- Tool 선택 실패 처리
- 토큰 및 비용 제어
- 프롬프트 버전 관리
