# 프롬프트 엔지니어링

## 1. 목적

Agent가 BOM 전문가 역할을 수행하고, 적절한 Tool을 선택하며, Tool 결과를 벗어난 추측을 하지 않도록 프롬프트를 관리한다.

## 2. 시스템 프롬프트 구성 요소

- 역할과 전문 분야
- 지원하는 업무 범위
- Tool 사용 원칙
- 데이터가 없을 때의 처리
- 답변 형식
- 보안 및 금지 행동

## 3. 핵심 프롬프트 원칙

- 조회 가능한 정보는 Tool을 사용한다.
- 제품 ID나 자재 ID를 임의로 만들지 않는다.
- Tool 실행 실패를 성공처럼 설명하지 않는다.
- 계산과 검증은 Python 결과를 따른다.
- 근거가 되는 ID, 버전, 상태를 답변에 포함한다.
- 질문이 모호하면 데이터 조회 전에 필요한 정보를 요청한다.

## 4. Tool 설명 작성 기준

좋은 Tool 설명은 다음을 포함한다.

- 어떤 질문에서 사용하는가?
- 어떤 입력이 필요한가?
- 무엇을 반환하는가?
- 비슷한 Tool과 차이는 무엇인가?

## 5. 평가 항목

- 올바른 Tool 선택률
- 필수 인자 추출 정확도
- Tool 미사용 질문의 자연스러운 응답
- 결과 근거 일치율
- 환각 발생률
- 오류 메시지 품질
