# FAQ - ADD 요청에서 추가 대상이 명확하지 않을 때 처리

## 질문

추가해줘라고만 요청하고 어떤 자재나 ASSY인지 말하지 않으면 어떻게 하나요?

## 답변

전체 자재 후보를 무차별 조회하거나 분석을 시작하지 않는다. 자재코드, 자재명, 품목군, ASSY 등 추가 대상을 먼저 사용자에게 확인한다. 대상이 명확해진 뒤 해당 범위에서 후보 탐색과 평가를 수행한다.
